# Contributing to KernelLab

First off, thank you for considering contributing to KernelLab! It's people like you that make learning OS concepts accessible and fun for everyone.

## Current Project State
**KernelLab is currently in active development.** The core architecture is still being built out. 

Because of this, large architectural changes or new module implementations submitted out of the blue might conflict with the ongoing roadmap.

## How You Can Help

### 1. Found a Bug or Have an Idea?
If you find a bug, typo, or have a suggestion for an improvement, please **open an Issue**. 
- Describe the issue clearly.
- If it's a bug, provide steps to reproduce it.

### 2. Want to Write Code?
Before you spend time writing a massive Pull Request:
1. Check the existing Issues to see if someone is already working on it.
2. **Open a new Issue** to propose your feature or fix. Let's discuss it first to make sure it aligns with the current goals and architecture.
3. Once we agree on the approach, feel free to submit a Pull Request!

### Pull Request Guidelines
- Keep your PR focused on a single feature or bug fix.
- Ensure your code follows the existing C++ style used in the repository.
- Write clear, descriptive commit messages.

Thank you for helping make KernelLab a great resource!
